=== Comunidad Digital y Solidaria ===
Tema de WordPress del Grupo de Oración Divino Niño Jesús (RCC, Capilla Divino Niño).
Requiere: WordPress 6.6 o superior, PHP 8.0 o superior. Sin plugins obligatorios.

== Instalar (una sola vez) ==

1. Apariencia → Temas → Añadir nuevo → Subir tema → elegir el archivo
   cds-parroquia.zip → Instalar ahora → Activar.
2. Herramientas → Contenido inicial → "Crear contenido inicial".
   Crea las 6 páginas, sube las fotos, pone el escudo como logo,
   arma el menú, carga las preguntas del bot y deja "Inicio" como portada.
3. Ajustes → Datos del sitio: llenar WhatsApp, formularios de
   Google y, si se usa, la hoja de avance de donaciones.
4. Ajustes → Datos del sitio → Instagram en la web: pegar el token
   (guía: docs/guia-instagram.md del repositorio). Desde ahí las
   publicaciones de Instagram aparecen solas en Inicio y Comunidad.

== El día a día (sin saber programar) ==

* Cambiar un texto, un horario o una foto: Páginas → abrir la página →
  hacer clic sobre el texto y escribir → Actualizar.
* Etiqueta amarilla "Ejemplo / Por confirmar": seleccionar el bloque →
  panel derecho → Estilos → "Predeterminado". La etiqueta desaparece.
* WhatsApp, formularios, ubicación, redes y campaña de donaciones:
  Ajustes → Datos del sitio. Un cambio ahí se ve en todo el sitio.
* Bot: menú "Preguntas del bot". El título es el botón, el contenido es
  la respuesta y las "Palabras clave" son las formas de preguntarlo
  (en minúsculas y sin tildes).
* Fotos de un evento: agregar un bloque "Galería" y, en el panel
  derecho → Estilos, elegir "Carrusel" (se desliza) o
  "Viernes (miniaturas)". Al tocar una foto se abre en grande.
* Menú: Apariencia → Editor → Navegación → "Menú principal".
* Colores: Apariencia → Editor → Estilos.
* Redes: el bloque "Síguenos en redes" usa Instagram, Facebook,
  WhatsApp y correo de Ajustes → Datos del sitio. Si un dato está
  vacío, su bloque no aparece.

== Reglas ==

* Publicar fotos solo con permiso. Sin fotos de menores de edad mientras
  no exista un criterio del grupo.
* La web nunca recibe dinero: las donaciones son solo en especie.
* El formulario de ayuda promete anonimato: en Google Forms debe estar
  desactivado "Recopilar direcciones de correo electrónico".
